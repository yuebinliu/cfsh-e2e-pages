草草的睡了

Posted on February 4, 2008 by admin

睡觉；累了。这几天没怎么上来看看。睡觉，考试，考试。 起点应该要高，这是很肯定的了。老头也说过了，很奇怪的事情，当你明白一件事情的时候总有人在这个时候和你谈到这个问题。 也许很多时候，或者很早的时候就有人谈过这个问题，只是那个时候你并没有意识到这个问题或者意见的重要性，于是被忽略了。 所以可以肯定的是 ，我们一直忽略了很多重要的东西，很多追悔莫及的东西，很多人和事，很多关心我们的人和重要的事情。莫非这就是生活。 从这里我们可以知道名师的重要性。生活还将继续，名师却越来越少？朋友越来越难。想起了高中老师，大学生活是美好的，你在那里可以交到很多的朋友，当你进入了社会，你会发现真正的朋友越来越难。

雪

Posted on February 1, 2008 by admin
