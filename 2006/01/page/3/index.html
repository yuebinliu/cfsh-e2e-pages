平价

Posted on January 14, 2006 by admin

 平价眼镜，今天上班路上看到的。 平价，这个词也快接近泛滥。 最近听说医院也要搞平价的了。当然是政府搞平价医疗。本来我对平价还有一丝好感的，但是听说是政府统一搞平价，就觉得有点不爽了。很多事情只要和政府联系起来都成了鸡肋 以前一个家伙说了“让一部分人先富裕起来”。现在搞平价，不知道是实际意义更大，还是一个姿态，或仅仅一个缓冲手段？ 对于平价，我不敢苟同。我到期望369等的出现，完全放开医疗。有钱人就享受好的医疗，没钱的就去一些相对廉价的。我相信在一些民营资本的介入，就医并不会比我们现在更加的艰难，相反可以花很少的钱享受同样的服务。（个人的想法，也许很理想话，并不可行。）   了解平价。解读更多。 建立平价医院是一个伪问题 卫生部：平价医院寄望在地方政府 【内容提要】:何谓平价？词典解释为公平的、普通的价格。中国现在的医院，绝大部分是公共医疗系统中的公立医院，理应是公益性、非营利性的，其价格当然应该是公平的、普通的价格即平价，换句话讲，公立医院本身就应该是平价医院。而卫生部强调的平价医院，却是特指的，现在还没有、将要去建立的医院。这么一来，显然就把面广量大的本来就应平价的公立医院划在了平价之外。

Wiki发布系统的选型”

Posted on January 13, 2006 by admin

虽然经历过使用Wakka被色情网站盗链当作图片服务的攻击，但一直没有放弃寻找一个Wiki平台的努力。知道最近休假期间，分别尝试了2个Wiki平台的搭建过程，算是对Wiki系统的发展有了一个初步的了解。尤其是初步试用了TWiki的DakarRelease的发布(稳定Beta版)和MediaWiki的1.5的发布。感觉Wiki发布系统在2005年成熟了很多。 和很多开源产品一样，开始的多种系统会向少数优秀平台集中：好比Blog发布工具，最后都集中到MovableType(Perl)和WordPress(PHP)这2个平台上，Wiki的发布系统也在向少数平台集中。我了解了Perl/PHP/Python/Java这几种开发语言的主流Wiki平台： Perl: TWiki 非常著名的企业Wiki写作，在很多大公司有广泛的应用，非常完善的权限管理 PHP: MediaWiki(就是WikiPedia维基百科等项目的后台发布系统)，非常适合大规模/丰富主题的Wiki平台搭建； Java: Confluence虽然商业版本的收费(开源)，但是对于非盈利组织是免费的，Apache基金会的很多项目都是用Confluence+JIRA(变更管理工具)协作开发； Python: TRACTrac和SVN的集成是Python内部协同开发环境的绝妙搭配； 1/12/2006 5:01:41 PM Post by[车东[Blog^2]]  鉴于gmail的繁忙，无法邮件发布，我就手工贴一下吧，做个参考。

我看十大笑话之二

Posted on January 11, 2006 by admin

2、”中国教育改革是成功的！一个承担着教育规模为世界之最的教育，实现了”两个跨越”：使85%以上的人接受了义务教育，使20%的人接受高等教育” ——12月22日教育部新闻发言人王旭明与网民交流。 这让我想到一所中学的雄猩撞志“五年内达到世界发达国家的中等水平。” 原谅我对教育行业的不了解。不了解发达国家的中等水平到底是什么程度。但听听这个号子就好笑。“水平”你以为也象写字本里的文字是可以随意复制的吗？ 很是奇怪，怎么某些人就这么缺少头脑，这种昏话也敢放出来。说远了，回到正题。 笑话２似乎只要把人都弄上学了教育改革就是成功的。那些数字的确够让人骄傲的，的确要理解我们现在的领导，目前的国情这样确实不错了。但是把这样的话放出来就是笑话！或许是我们某位同志的断章取义造就了这句笑话，但我还是认为尽量少说这样的话。有种让人不舒服的感觉。就如某件产品，我被购买的最多，我就是最好的？或者说，我们只负责生产，至于产品是不是次品一概与我无关。 怎么看都是在为自己找借口，推托责任。少说为妙。

决策者说

Posted on January 11, 2006 by admin

昨天看了 决策者说 之专访 教育部部长周济。 他提到职校和高校的升学比例超过1：1是浙江省，一个南方的地区，这个与“人们”原本的想像是相反的。然后他给出了理由，“观念的问题”。 我原来不想对此做出评价的，但是觉得有必要说说。因为 决策者 们 在上面过的太久了，早忘了自己的前n辈原来只是出生农民的。 他说观念是主要的。我说经济是主要的。上学几万块对他们来说只是九牛一毛，算不得什么。可对某些家庭却是一大比。很多的贫困地区，读不了高中，直接就出来打工挣钱糊口了。 他说观念确实没错，可不是深层次的，关键还是没钱。经济决定了他的观念。 很多高官自认为自己知道问题在哪里，有时候也的确知道在哪里。可就是没有行之有效的办法去解决问题。总喜欢上升到一个理论上谈问题。这可能与中国的传统有关。儒。
