异想 天开

Posted on January 26, 2006 by admin

本想把我的blog改成 “异想  天开”的，用google搜索了下，发现有人捷足先登了。 早晨乘车，思绪乱飞。最近很多人都很迷惘或无奈，如hopesome、……podcast的确很火，传统媒体的确已见颓势。虽然不知道ipod是什么东西，大概是个很cool的电子产品，原谅我的无知。我想的是wireless无线，也许我们目前所憎恨的媒体也可以从1.0到2.0。不妨把传统的媒体看成1.0，把podcast做2.0。这里涉及到1.0和2.0，很遗憾，目前我依然不知道2.0和1.0到底是什么？谁能告诉我吧。 但是我的异想还是要继续。以前的radio，估计没什么人会去听，我就听的很少，因为他只是巨头到个人的单方面的传播，你不能左右。2.0似乎人人都的那个巨头了，广播者发生了改变。 我在想，不管谁做播放者，总得有个源存在。这个源不能是空气，必须把他存储起来，供大家使用。也许这才是关键的所在—–存储介质。 听说google买了遍布美国的光纤网络。作为传播介质，光纤我到不认为是很主要的，也许在未来的一段时间光纤会占主导地位。但是别忽视了无线技术。 看样子无线目前的确已经渗透到了生活的方方面面。gprs，gsm还有什么3g,5g？也许未来的一天，我们不在需要目前的看似小巧的mp3，我们需要的仅仅是个耳机，这个耳机可以无线到互连网，就这够了。

wordpress升级到2.0的 一些问题

Posted on January 26, 2006 by admin

早就看到WordPress 2.0发布的消息，可是由于虚拟主机的原因，到昨天晚上才得以对这里升级。正如海豚说的，升级很顺利，一步就ok了。 对于本站大部分作者来说，2.0增加的TinyMCE确实很有用。写作界面也漂亮多了。 不过在使用Jerome’s Keywords Plugin插件的时候遇到问题，尽管作者的blog上有一些解答，仍然无法解决我的问题。前两天刚刚改为power by tag，就遇到这种事情，实在有些尴尬，幸好在天佑那里见到Ultimate Tag Warrior的使用教程，并且他也提供这个插件，帮助我们这些GFW之内又懒得找代理的人。天佑是个热心人，很快有了回应。顺利安装这个插件后，blog又恢复原来状态了。Ultimate Tag Warrior功能强大，对于我这样的简单应用者，不用改什么代码，在”选项“和”管理“中设置一下，再创建一个tag cloud就够了。至于更进一步的运用，像是An inline tag-adder、tagset等，看起来似乎很有意思，等有时间再试验吧。 关于新的tag/关键词的使用方法，会在 把分类变成关键词这篇帖子中说明。 很值得参考 via wordpress升级到2.0的小波折
