睡觉了 08-01-19

Posted on January 19, 2008 by admin

一天什么都没做，睡觉了。

“你少废话吧，别成天活在自己给自己编织的故事里咯而”

记得。

这些日子实在是无奈。
明天 星期天 上班，痛苦。天冷了，喝点黄酒暖暖自己。

很多东西发现即便是再好的朋友都不能共享的，可怜。是我不想说出来，也许每个人都有自己的秘密吧。

不能共享实在是痛苦的事情。明天又是崭新的一天，孤苦终老吧。往事已矣，只有回忆，嘎嘎。

“不能得到的永远是最美的”。

无聊，寂寞，孤独

Posted on January 18, 2008 by admin

周国平的《人生哲思录》感觉他的一段话说的很好
　　
　　：
　　 “无聊、寂寞、孤独是三种不同的心境。无聊是把自我消散于他人之中的欲望，它寻求的是消遣。寂寞是自我与他人共在的欲望，它寻求的是普通的人间温暖。孤独是把他人接纳到自我之中的欲望，它寻求的是理解。
　　 无聊者自厌，寂寞者自怜，孤独者自足。
　　 庸才无聊，天才孤独，人人都有寂寞的时光。”

没什么写的

Posted on January 18, 2008 by admin

嘎嘎。
听到一首歌是如此的熟悉，真的很奇怪。

Jeffrey Osborne – Emotional-(1986) -10-Come Midnight.mp3

虚妄中度过一天 。

发现自己很懒，缺少恒心。事未做先想各种困难。有人说我很理智，其实发现自己不能说理智，往往做事情都是三把火，坚持不了几天。事前想的挺美，大多半途而废，也许与家庭，基因都有关系。

基本可以肯定 这辈子 将 孤苦终老。这种人，是无用的人。

nice day

Posted on January 17, 2008 by admin

从99年接触网络，00年接触个人主页，03 年自己用dz架设坛子，04的用wp也记录下了不少自己的历程，然而数据都丢的丢，删的删，基本都不存在了 。一直很佩服“中国茶”，能把数据详尽的记录到现在，少说也有几个年头了 ，虽然很早就体会到“稳定”的 重要性，虽然知道“无志者常立志”，然而自己还是不可避免的到处奔波，虽然自己的虚拟主机就放在那里，然而最终还是选择gg的blogger ，虽然 blogger老是被和谐，然gg就是 gg，gg让我很放心的吧数据交给她，比对我自己的电脑都方一百个心。

上面其实是以前写的，现在网络环境越发的恶劣，即便如gg般强大在gv的面前也显得像个小孩子般无辜无奈。就不说我的zcde.com莫名的被封了ip，到现在依然是无法访问，不说 google的host计划被封，不说google的domain计划被封，不说现在blogger的的图片都不能正常显示了，gg blogger一步步被蚕食，不知道我现在加入blogger是不是明智之举。

说来估计没人会相信，我现在连个blog都没了。数据一再的丢失，从04用的wp数据现在固然是找不到了，zcde貌似也不会回来了，虽然通过代理偶尔还可以访问，但是数据无法备份，今天很绝望的发现就是zcde再也回不来了，原来是我的玉米过期了 ，虽然发现了续费回来，但主机不可避免的检测不到我的a记录而把zcde删除掉了，默哀，德国一个非常强悍的虚拟主机。里面的记忆怕是都没了。

虽然目前自己买了美国的虚拟主机，然而依然不愿意吧zcde迁移到这个bluehost上，而且bh也快到期了。现在就发现了，原来买了虚拟主机不一定就有空间用的，不然我目前怎么连个blog都没，居然还考虑在blogger安个家。可怜

昨夜再次的发现 原来 “我们每个人都很寂寞。”
