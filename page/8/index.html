某人说

Posted on July 17, 2010 by admin

学习可以是很快乐的事。

多久没听到这句话，所以让我们都很迷惘。记得大学英文课本中提到在国外留学的中国学生普遍用功，成绩比较好，问及原因，更多的是”负罪感”，对爸妈的负罪感，所以出了很多鸡窝里的凤凰。我们目前在教育孩子的时候更多的说的是”想爸爸当年多么苦……”“在外面挣钱多么苦……因为没文化”，都这个调调。
上了高中，体育课不见了，课外休息的时间少了，劈头盖脸的填鸭式教育多了，于是我们越来越不快乐。兴趣变成可以完全抹杀的奢侈品，所以我们迷惘了。我有点赞成目前的中国教育是愚民教育。
“授人以鱼，不如授人以渔”，这很多人都会说；“素质教育”，在中国特色的领导嘴巴里手掌中的闹腾了很久很久衬底沦为一个符号一个工具，我替提出这个词的XX感到悲哀。这有点像东施效颦，不过东施是很可悲的，但在中国，领导都成了西施，无可反驳。

说了那么多，学习能有一点点快乐么？我仍记得小学时最喜欢我们的体育班主任老师了，因为我们可以踢足球打篮球。也许玩的时间少了，所以现在无所事事摸不着方向的人多了。这有点像河里的水，有点像江湖。

今天狂郁闷

Posted on April 21, 2010 by admin

我承认我很菜。
用来三年的hp的本本，今天就出问题了。先听我慢慢讲来。

打开本子，输入密码，老出问题，密码不对，有过经验，只要重启或者换个域登录就可轻易地解决问题，偏偏今天switch user 不见了，于是重启，结果还是卡住，郁闷，难道是键盘出问题了。于是想到看能不能恢复系统，或许就好了，虽然数据的丢失并不太能接受，开机选择maxdos，结果也要密码，偏偏输入的时候也出问题，ghost都没法做。狂郁闷，这可咋办？想到从u盘引导个新系统，结果只有一个usb接口能够被正常识别，狂汗，看来问题不仅仅是一个了，完蛋，肯定是线路出问题了。。难道是我前几天看电源不行，就重接了下导致线路短路，于是把电源拿掉，看看使用电池能不能进入，问题依旧。
没办法，只能打开台式机，搜索一阵，发现有线路问题，说道“用外接键盘能正常，笔记本不行，那就是笔记本地键盘出问题了”，于是拔掉鼠标，弄个外接，正常登录系统。也有说道，木马也能导致类似问题，于是360一阵狂杀，找到两个小木马，虽然这些木马我是默认的，并不是真的木马，但也有所期待。结果问题依旧，看来也不是木马。。

并且发现自己的usb接口也有问题，只一个能使用，这个我知道，是usb2.0 和1.1 不兼容的问题，只要停用usb2.0就可，偏偏停用后依然只支持一个接口，前几天还可以的啊。。更郁闷了，要知道我一边搜索，一边打字，中间不停的切换鼠标键盘usb插拔是何等痛苦的一件事情。

没办法，继续搜索，修改管理员密码，重装个dos管理登录器，绕过maxdos的登录密码。记过突然发现也有个小朋友也有类似问题说到“这次我按了FN+num lk键没用，是不是键盘坏了”，一阵激灵，赶紧按下FN+num lk，尝试键入出问题的“O”，居然就好了。狂汗，我还说怎么键入“O”怎么就出来6呢。。。原理是数字锁定了。。。。用了三年的本子，居然不知道有这回事，我好菜！
只是现在能够写点东西，但usb问题依然得搜索了。今天差点就重装了系统，07年的数据，这个重装打补丁，装杀毒不知道到什么时候，幸亏maxdos有密码，不然可真的走绝了。。继续找unknow usb device的解决方法去，不知道这到底是怎么了。众说纷纭啊，有说bios设置usb 2.0 disable的，反正更多的说法就是你驱动没装，要么就是usb接口坏了。。这一阵无语，这才发现大多给出答案的都是些没经历过或者直接说是半瓶水，哐当晃荡的。大概生活中也是如此。

天气不错

Posted on April 7, 2010 by admin

早晨起来，阳光明媚，空气清新，深吸两口，心情也变的愉快起来。

上班至9点，想起一件事，阳历换算下，居然是农历2月23，“My birthday”，于是“教授”请吃面，来一碗，味道不错，撑着了。

很迷信，都说过生日的那天，天气不错，运程就会很好，于是我想似乎总有一半的人会很悲剧，如果日日都如梅雨天气，那岂不是天降降大任于世人么？磨其筋骨，饿其体肤，苦其心志，太多的悲剧了。于是我偷笑了一天，回到家说的第一句话“今天天气不错，天上白云朵朵。”
有意思的是，今天把科室的生日都摸了个遍，发现两个白羊，两个双鱼，这让我有点怀疑星座。一个白羊我总以为是双鱼才对，一个双鱼除了有些爱幻想，其他我怎么看都不符合。难道是面具？反正摸不透。不管怎么样，有个白羊到是挺符合的，很BH。

需要多少瓷砖

Posted on April 5, 2010 by admin

一种瓷砖长24cm，宽18cm，问需要多少这样的瓷砖才能拼成一个正方形？

小学生的题目，我想了想，比划了两下，给出答案12。草稿如下：
24x=18y
4x=3y
xy=12
所以需要12块，可惜解释不通。穷尽脑汁，实在想不到如何解释，也试着baidu和通过面积包括画图来解释，无果。比较合适的解释就是拿3块砖的横着放，4块砖竖着放，然后相乘就是需要的砖数。

其实比较正统的解释，就是求他们的公倍数,结果为72.
72÷24=3
72÷18=4
3×4=12

这样似乎比较对小学生比较容易行的通。给那些为此绞尽脑汁的家长同志们。

想说的话

Posted on April 5, 2010 by admin

还是last.fm好,可以很方便的共享，发到自己的邮箱里面，然后可以搜索搞下来；拒用yahoo，音乐的名字都没的，无从搜索。

touch是最新的MC开头的三代，很悲惨，暂时无法破解，不完美的破解都无法做到，忍了，据说十号会出破解，但愿那些纠结于3代的小朋友不要出现这种低级失误，向往的未必用着就爽。总之会遇到各种错误，刷3.12会出现28错误，使用红雪破解3.13会出现waiting for boot 然后就定在那里，无法继续，悲剧了。老实说，touch真的不爽，还是直接iphone吧，当你掏出touch却发现没有网络的时候，看着那些诱人的程序，你会极度的不平衡，却无奈只能当mp3，心中还会念叨着这mp3的性价比啊，那个郁闷。

大家都很墨迹。foolish game。
[dewplayer:http://php.chol.com/%7Epcj819/bgm/file/Foolish_Games.mp3]

每天分出一点点时间做一件事，我们可以做的很成功很伟大，这不难看出为何老爷车越老越名贵，文化需要沉淀，老男人的声线性感，三代才能出贵族，这都是需要积淀的。这些我做的不好，感觉身边的每个人似乎都比我做的好，dayan能够坚持不懈的固守一个阵地，写出的东西时而煽情，时而技术，这厮真乃风月高手，我所不及。有时候看着每天记账的单子被我一个个堆积在那里，半年居然也很可观，很沉重，居然也有点小小得意。对比之下，我的生活可谓糟糕无比，事关自己，必定高高挂起，与工作中判若两人。有时候，也许不必过多在意别人的目光，也许allrnb就能坚持下来，也许不要那么的浮躁，每天为了统计执著，也许allrnb现在的的ip必定很可观，一切都是也许，最有希望的被我扼杀在摇篮中，那段时间我扼杀了两个重要的东西，导致到现在我只能坐在这里干瞪眼，想着自己走过的路做过的事。

明天下午需要做的事：
1，重拾过去，能做到么？allrnb.org业已被他人注册，我能掌握的只有allrnb.info。然而人才是不可或缺的，团队团队啊。
2，定义blog主题，结合我的工作，写出点新意的文章，至少也能吸引点眼球。昨天居然在梦里想到几个好的话题。医疗中的悲哀，社会的价值导向，抗生素的滥用，不必要的重复检查，专家的迷信，药代给的回扣，糊弄大众的招标，太多的话题，恐怖不是我三言两语就能说透的，也不是我的文字就能表达的清楚的。但凡想想大概到处都是如此。说到这里插个小小的笑话，两个人穿着工作服的去买房，前台小姐爱理不理，找到经理，一人一套别墅，前台小姐眼睛都直了，笑话笑话。所以说，大家都一样。
