没有什么大不了

Posted on April 6, 2005 by admin

没有什么大不了，地球没有了谁都一样可以转动，人们也不并不是一定非得需要某种寄托才能生存下去。

天还是天，地还是地，你还是你，我还是我…………….

互联网今日焦点Coral,P2P分布式的网站内容服务

Posted on April 5, 2005 by admin

原文地址：
http://it.slashdot.org/it/04/08/28/2330252.shtml?tid=95&tid=218

Eloquence writes “infoAnarchy reports that Coral, a peer-to-peer webcaching system, has gone into public beta. Currently the Coral node network is hosted on Planet-Lab, a large scale distributed research network of 400 servers. You can use Coral right now by appending “nyud.net:8090″ to a hostname. View Slashdot through Coral. Is this the end of the Slashdot effect?”

什么是Coral？简而言之，Coral是一个P2P分布式的网站内容服务，可以参看官方介绍
Coral的使用也很简单，只要在想访问的网站后面加上nyud.net:8090，就OK了。
这简直是一个绕开封锁的的利器！

举个例：
“http://www.gamez.com/bbs”被电信封了无法访问，那么我们可以通过coral来突破封锁，只需这么干
“http://www.gamez.com.nyud.net:8090/bbs”
就可以访问了！
或者到它的主页输入网址
http://www.scs.cs.nyu.edu/coral/

死中国电信，见鬼去吧！

b2evo的用户级别设置

Posted on April 5, 2005 by admin

Since verison 0.8.9 b2evolution includes advanced groups/users permission management. Thus, user levels are used only in very specific situations where we haven’t implemented permission management yet. Here is what user levels will allow.

Level 1 and above
Ability to view link to admin section (users with level 0 can still login into admin, but there’s no good reason for that, except in rare cases, so they’ll have to find out by themselves…)
Ability to upload images

Level 2 and above
Ability to generate static pages

Level 5 and above
Ability to edit timestamp on posts

这下总算可以让用户发图片了

b2evo的主要特性有：

支持多个blog，每个blog之间信息可共享
支持多语种，中文支持不错，有现成的中文包，utf8字符集也支持得很好
支持skin功能，每个blog可选择不同的skin
相当完善的系统功能，包括文章分类功能
b2evo的网址: http://b2evolution.net

越来越难以取舍了

Posted on April 4, 2005 by admin

csdn 还是不错的,界面我也瞒喜欢,很醒目,很强大,但就是不稳定,有时候速度会很慢,不堪忍受

yahoo 360比较的人性点.可惜速度太慢,界面我也很喜欢,就是功能难以捉摸,有些方面不是很强大.最大最大是缺点就是速度实在慢的可以,光blog还可以看看,其他的就不敢恭维了.

自己建立的blog ,发现耗费了太多的精力,完全没有必要.就目前这个有些地方我总觉得不是我想要的,功能上虽然很强大了,可总不是那么的方便,（还是坛子来的方便直接）不是技术的问题,好像他真的有意如此.

yesky 过于商业化了,界面也不是很喜欢,其实他用的程序和csdn的一样,比csdn的稳定,速度也很不错,唯一的缺点就是太商业了,自己的空间就小了，

其他什么的，不想用了。还是把资料都放在自己的电脑上最实在。可惜如此网络不再有魅力
